# 主页面扫码登录弹窗设计

## 目标

- 将扫码登录从直播控制页卡片迁移到主页面内的模态弹窗。
- 未登录时在左下角用户区域提供明确的登录按钮。
- 登录成功和失败均提供清晰反馈。

## 交互

1. 未登录时，侧边栏底部显示“扫码登录”按钮。
2. 点击按钮后打开主页面居中的模态弹窗，并显示遮罩。
3. 弹窗打开后自动生成二维码，展示等待扫码、已扫码待确认等状态。
4. 用户可通过右上角关闭按钮或遮罩关闭弹窗；关闭时停止二维码轮询。
5. 登录成功后自动关闭弹窗、刷新用户区域，并显示全局成功提示。
6. 二维码过期、生成失败或轮询失败时，弹窗保持打开，显示原因和“重新生成”按钮。
7. 登录后侧边栏底部恢复头像、昵称和退出登录按钮。

## 页面调整

- 删除直播控制页的扫码登录卡片。
- 直播间配置卡成为直播控制页的唯一主要卡片并占满可用宽度。
- 保留主页面内部标题、连接状态、侧边导航，以及已实现的原生菜单栏移除。
- 不修改桌面浮窗和 OBS 页面。

## 结构与状态

- 登录模态框静态结构放在 `src/renderer/index.html`，样式放在 `src/renderer/styles.css`。
- 新建独立的登录弹窗控制模块，负责打开、关闭、状态文本、二维码和重试界面。
- `src/renderer/app.js` 继续负责调用现有 preload 登录 API，并将结果交给弹窗控制模块显示。
- 关闭弹窗或登录结束时必须清理轮询定时器，避免后台继续请求。

## 验证

- 单元测试覆盖弹窗打开、关闭、成功、失败和重试状态。
- 完整测试覆盖现有登录、直播连接、更新和主题功能不回归。
- 使用实际 Electron 页面验证左下角入口、遮罩层、二维码弹窗和直播页布局。
