# 字体与气泡样式增强设计

## 目标

将字体名称自由输入升级为可选择的系统/导入字体列表；允许导入并持久保存字体文件；增加字体描边开关；为答谢气泡增加外形预设、透明度以及单色/渐变模式。软件实时预览、桌面浮窗和 OBS 浏览器源使用同一套渲染配置。

## 字体列表

- “字体”控件改为下拉选择，不再要求用户直接输入字体名称。
- 下拉列表分组显示 Windows 系统字体和已导入字体。
- 系统字体由主进程读取 Windows 已安装字体信息，按名称去重并排序。
- 保留旧版 `fontFamily` 字符串兼容：若名称存在则自动选中；若系统字体列表中不存在，仍加入一个“原配置”选项，避免升级后字体被静默替换。
- 默认字体仍为 `Microsoft YaHei`。

## 字体文件导入

- 支持 `.ttf`、`.otf`、`.woff`、`.woff2`。
- 使用纯 JavaScript 字体解析库读取字体内部家族名，不引入需要本机编译的原生模块。
- 导入成功后，将文件复制到 Electron 用户数据目录的 `fonts` 子目录。
- 文件副本按内容哈希命名，重复导入相同内容时复用已有记录和文件。
- 字体记录包含稳定 ID、内部家族名、显示名称、格式和受控副本路径。
- 若字体包含多个名称，优先使用本地化家族名，其次使用英文家族名，再使用完整字体名。
- 损坏、空文件或不支持的字体显示明确错误，不复制文件、不修改当前选项。
- 已导入字体列表随设置持久化，下次启动自动恢复。
- 本次不增加字体删除功能，避免误删正在使用的字体。

## 字体加载与安全

- 导入字体通过动态 `@font-face` 加载，并使用稳定的内部 CSS family ID，显示名称不直接作为 CSS 标识。
- 主界面和桌面浮窗通过现有 `asset://` 协议读取字体副本。
- OBS 页面通过 localhost 的专用字体资源路由读取；仅允许访问用户数据目录的 `fonts` 子目录，禁止任意路径读取。
- 实时预览、桌面浮窗和 OBS 在字体加载完成后重新测量整体内容并执行自适应缩放，避免字体切换后裁切。
- 字体文件读取失败时回退到 `Microsoft YaHei, sans-serif`，同时保留配置供用户修复。

## 字体描边

- 新增 `strokeEnabled` 布尔配置和“启用字体描边”开关。
- 旧配置迁移：不存在 `strokeEnabled` 时，`strokeWidth > 0` 迁移为开启，否则关闭。
- 描边关闭时，描边宽度和颜色控件禁用，渲染时使用 `-webkit-text-stroke: 0 transparent`。
- 描边开启时继续使用现有 `strokeWidth` 和 `strokeColor`。
- 描边开关参与实时预览，并同步到桌面浮窗和 OBS。

## 气泡外形预设

新增 `bubbleStyle` 配置，提供：

- `rounded`（圆角）：当前圆角矩形风格。
- `pill`（胶囊）：大圆角和更宽横向内边距。
- `card`（卡片）：较小圆角、规整内边距和轻微边框。
- `glass`（玻璃）：中等圆角、半透明边框、阴影和轻微背景模糊。

预设只控制圆角、边框、阴影、模糊和内边距，不覆盖用户选择的颜色和透明度。

## 气泡颜色与透明度

- 保留 `bubbleEnabled` 总开关；关闭时所有气泡配置控件禁用，渲染背景透明且不使用边框、阴影或模糊。
- 新增 `bubbleOpacity`，范围 `0–100`，界面使用滑块并实时显示百分比。
- 新增 `bubbleGradientEnabled`。
- 渐变关闭时只显示一个 `bubbleColor` 颜色选择器，并用该颜色和透明度生成纯色背景。
- 渐变开启时额外显示 `bubbleColorSecondary`，从主颜色渐变至第二颜色，两端共享同一透明度。
- 透明度只影响气泡背景，不影响文字、描边、边框和阴影。
- 旧版 `bubbleColorStart`、`bubbleColorEnd` 若能解析为颜色与透明度，则迁移为新的主色、第二颜色和透明度；旧两色不同时默认开启渐变。

## 界面交互

- 字体行包含字体下拉框和“导入字体”按钮。
- 导入成功后立即把新字体加入“已导入字体”分组并自动选中。
- 描边开关关闭时，对应颜色和宽度控件显示禁用状态。
- 气泡总开关关闭时，气泡样式、透明度、渐变和颜色控件显示禁用状态。
- 渐变关闭时，第二颜色控件隐藏而非仅禁用。
- 所有样式控件在输入时立即更新实时预览；“保存样式”继续负责持久化。
- 页面在主窗口最小尺寸下保持控件文字完整、无横向溢出。

## 数据与接口

- `state.importedFonts` 保存可公开给渲染器的字体记录，不包含用户选择的原始外部路径。
- preload 新增：获取字体列表、导入字体。
- 主进程负责选择文件、验证扩展名、计算哈希、解析字体名称、复制文件和保存状态。
- `config.fontFamily` 保存用于显示和回退的家族名；新增 `config.fontSourceId` 指向导入字体，系统字体时为空字符串。
- OBS 状态接口可返回导入字体的 ID、显示名称和 localhost 资源 URL，不返回磁盘绝对路径。

## 测试策略

### 自动化测试

- 字体扩展名验证与重复哈希去重。
- 字体记录到 CSS family/source 的映射。
- 旧描边配置迁移。
- 旧气泡颜色配置迁移。
- 十六进制颜色与透明度到 RGBA 的转换，覆盖 `0%`、`100%` 和中间值。
- 四种气泡预设输出的圆角、边框、阴影、模糊和内边距。
- 单色模式不引用第二颜色，渐变模式引用两种颜色。

### 渲染验证

- 系统字体下拉列表存在且可切换。
- 导入有效字体后自动选中，重新启动后仍存在。
- 损坏字体显示错误且当前字体不变。
- 描边开关正确影响控件状态和实际画面。
- 气泡总开关、四种预设、透明度边界、单色/渐变切换正确。
- 软件预览、桌面浮窗和 OBS 渲染一致。
- 长 SC 在 720P、1080P、2K、4K 以及最小桌面浮窗中完整显示。

## 完成标准

- 用户无需输入字体名称即可选择系统字体或已导入字体。
- 四种字体文件均能解析内部名称、复制并持久使用。
- 描边可独立开关，旧配置升级结果符合原显示状态。
- 气泡具有四种外形、独立透明度和单色/渐变模式。
- 所有新设置实时预览并正确保存。
- 桌面浮窗和 OBS 不出现字体缺失、样式不一致或文字裁切。
