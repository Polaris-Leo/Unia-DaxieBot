# 窗口菜单与直播控制布局设计

## 目标

- 完全移除 Windows 主窗口顶部由 Electron 提供的 File、Edit 等原生菜单栏。
- 保留应用内部标题、连接状态和侧边导航。
- 将直播控制页改为纵向布局：扫码登录卡片在上，直播间配置卡片在下。

## 实现

- 主进程在创建窗口前通过 Electron `Menu.setApplicationMenu(null)` 清除应用菜单。
- `live` 页面保留现有两张卡片及全部控件，仅将容器从双列布局切换为单列。
- 不修改桌面浮窗、OBS 页面、状态管理或连接逻辑。

## 验证

- 自动化测试检查主进程明确移除应用菜单。
- 自动化测试检查直播控制容器不再使用双列类，并保持扫码卡在直播间卡之前。
- 运行完整测试及 JavaScript 语法检查。
