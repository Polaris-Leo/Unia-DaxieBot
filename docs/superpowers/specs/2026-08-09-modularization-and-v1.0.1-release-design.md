# Unia 答谢助手模块化与 v1.0.1 发布设计

## 目标

在不改变现有用户行为、配置格式、preload API 和 OBS 地址的前提下，将集中在主进程与渲染进程入口文件中的职责拆分为可独立理解和测试的模块。完成后将应用版本统一设为 `1.0.1`，构建 Windows NSIS 安装版和便携版，并创建公开 GitHub 仓库 `Unia-DaxieBot`。源码推送到默认分支，两个 EXE 作为 GitHub Release `v1.0.1` 的附件发布。

## 范围

本次只做结构性重构、必要的测试补充、版本更新、Windows 构建和 GitHub 发布。界面视觉、业务规则、配置字段、用户数据目录、端口 `17321` 及 `/overlay` 路径均保持不变。项目继续使用 Electron、CommonJS 和当前原生浏览器脚本，不引入 TypeScript 或前端框架。

## 架构

### 主进程

`src/main.cjs` 缩减为应用组合根，负责创建共享依赖、注册生命周期并启动各服务。新增 `src/main/`，按职责拆分：

- 状态模块：默认状态、公开状态投影、配置规范化、持久化与广播。
- B站认证模块：Cookie 解析、二维码创建与轮询、用户信息获取。
- 直播模块：直播间解析、连接与断开、指数式重连、礼物事件标准化及分发。
- 字体模块：系统字体扫描、导入字体管理和公开字体列表。
- 窗口模块：主窗口、桌面浮层、显示/编辑状态及边界调整。
- OBS 服务模块：仅监听回环地址的 HTTP 静态资源与事件推送服务。
- IPC 模块：集中注册 preload 已公开的调用接口，并把请求委派给上述服务。

模块使用构造函数或工厂函数接收依赖，避免继续依赖入口文件中的可变全局变量。纯逻辑函数独立导出供测试使用。

### 渲染进程

`src/renderer/app.js` 缩减为初始化与事件绑定入口。新增 `src/renderer/app/`，拆分：

- 页面状态与导航渲染。
- 扫码登录、退出及直播连接控制。
- 样式表单采集、控件联动与配置保存。
- 字体注册与下拉选项维护。
- 礼物样式预览与自适应布局。
- 桌面浮层编辑及 OBS 清晰度工具。

浏览器端模块继续使用无需打包器即可加载的脚本组织方式，避免引入新的构建链。现有 `window.daxie` 接口保持兼容。

## 数据流与兼容性

状态模块持有唯一应用状态。认证、直播、窗口和 IPC 服务通过显式接口读取或修改状态；每次持久化后向主窗口、浮层和浏览器客户端广播公开状态。礼物事件由直播模块标准化后，同时发送到桌面浮层、主窗口提示和 OBS 浏览器客户端。

现有用户数据和素材路径继续从 Electron `userData` 读取。旧版 `settings.json` 不需要迁移，缺失字段仍由默认配置与样式规范化逻辑补齐。

## 错误处理

- 网络认证和直播错误返回可展示的中文消息，不让未处理 Promise 终止进程。
- 重连定时器在手动断开或应用退出时清理，并通过连接代次阻止过期连接恢复。
- 字体扫描或单个字体解析失败时跳过损坏条目，不阻断应用启动。
- 本地 OBS 服务启动失败时向主窗口报告状态，应用其他功能仍可运行。
- IPC 输入在服务边界完成类型和范围规范化，文件选择取消时保持原配置。

## 测试与验证

先为将要抽取的纯逻辑建立特征测试，确认测试在抽取前能覆盖现有行为；新增逻辑遵循红—绿—重构循环。重点覆盖默认状态合并、Cookie 解析、礼物标准化、公开状态投影、MIME 识别和渲染端配置采集。完成后运行完整 `npm test`、关键文件语法检查，并分别执行安装版与便携版构建。还需核对两个 EXE 文件名、版本资源及文件存在性。

## 版本、构建与 GitHub 发布

- 将 `package.json` 与 `package-lock.json` 的项目版本统一设为 `1.0.1`。
- `npm run build` 生成 NSIS 安装版；`npm run build:portable` 生成便携版。
- `release/` 继续由 `.gitignore` 排除，避免二进制进入源码历史。
- 初始化 Git，以 `main` 为默认分支，提交源码和文档。
- 通过已认证的 GitHub CLI 创建公开仓库 `Unia-DaxieBot` 并推送 `main`。
- 创建带注释标签 `v1.0.1` 和正式 GitHub Release，上传安装版与便携版 EXE，并在发布说明中概述模块化重构、兼容性和下载文件差异。
- 发布后读取 GitHub Release 页面，确认标签、公开状态和两个附件均可访问。

## 完成标准

1. 主进程与渲染进程入口只承担组合和初始化职责，各业务模块边界明确。
2. 现有自动测试与新增测试全部通过，关键 JavaScript 文件语法检查通过。
3. 应用版本为 `1.0.1`，安装版和便携版均成功生成。
4. GitHub 公开仓库 `Unia-DaxieBot` 包含完整源码和默认分支历史。
5. GitHub Release `v1.0.1` 对外可见，并包含两个可下载 EXE 附件。
