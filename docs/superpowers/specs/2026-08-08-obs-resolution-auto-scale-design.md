# OBS 分辨率自动缩放设计

## 目标

OBS 浏览器源在 720P、1080P、2K、4K 以及非标准分辨率下，答谢画面相对于画布保持一致的视觉占比；桌面悬浮窗行为不变。

## 缩放规则

- 以 1280×720 为设计基准，720P 的基础缩放倍率为 1。
- OBS 页面根据实际浏览器视口宽高计算基础倍率：`min(视口宽 / 1280, 视口高 / 720)`。
- 标准 16:9 分辨率对应倍率为：1080P 1.5、2K 2、4K 3。
- 非标准宽高比采用较小方向的倍率，保证内容比例不变且不因画布裁切。
- 在基础倍率之上继续执行现有的防溢出适配；文字、图片和气泡作为一个整体等比例缩放。
- 桌面悬浮窗不应用分辨率放大倍率，只保留现有的防溢出缩小逻辑。

## 实现边界

- 在布局工具中增加可测试的 OBS 基础倍率计算函数。
- OBS 页面计算最终倍率时组合“分辨率基础倍率”和“防溢出倍率”。
- 不增加新的用户设置，不修改现有字体、图片尺寸和四档清晰度配置。

## 验证

- 单元测试覆盖四种标准分辨率、非标准宽高比、无效尺寸和桌面端不放大行为。
- 自动测试确认现有防溢出逻辑不回归。
- 使用本地 OBS 页面分别模拟 720P 与 4K，确认 4K 最终基础倍率为 3，内容不会越界。
- 重新构建便携版并执行本地接口冒烟测试，结束后释放 17321 端口。
