# Unia 答谢助手（桌面版）

## 应用内更新

在“使用说明”页面可手动检查 GitHub Release，并选择 GitHub 官方源或 `gh-proxy.com` 加速源。便携版允许选择保存位置，下载完成后自动启动；安装版从 `1.0.2` 起使用 NSIS 更新元数据，后续版本可进行差分下载。由 `1.0.1` 首次升级到 `1.0.2` 仍需完整下载安装包。

从 `Unia-Danmuku` 的答谢链路提取出的独立 Electron 程序。只保留扫码登录、直播间礼物监听、答谢规则、素材/样式配置和透明桌面浮窗。

## 开发运行

```powershell
npm install
npm start
```

## 构建 Windows 程序

```powershell
npm run build
npm run build:portable
```

安装包和便携版使用独立命令构建。便携版会先在临时目录生成，成功后仅将最终 EXE 放入 `release/` 并自动清理中间文件。运行时配置、扫码登录 Cookie 和素材路径保存在 Electron 的 `userData` 目录中，不依赖原项目或独立后端服务。

## 使用

1. 使用哔哩哔哩 App 扫码确认登录。
2. 输入直播间号并连接。
3. 设置答谢样式与礼物规则。
4. 开启桌面答谢浮窗；可用四个测试按钮检查显示效果。

## OBS 浏览器源

程序运行时会在本机启动只监听回环地址的浏览器接口：

```text
http://127.0.0.1:17321/overlay
```

在 OBS 中添加“浏览器”源并填入该地址即可，推荐画布尺寸 `1920 × 1080`。桌面浮窗与 OBS 浏览器源共享配置与实时答谢队列。

目前监听普通礼物、盲盒、上舰和醒目留言。免费礼物及低于阈值的事件可按配置过滤。
